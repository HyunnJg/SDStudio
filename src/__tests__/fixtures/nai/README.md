# P0-03 오프라인 픽스처

직접 작성한 합성 입력/기대 출력이며 서비스 응답 캡처가 아니다. 모델 ID도 의도적인 가짜 값이다. 기본값·action·params_version·샘플러 ID의 모델별 유효성은 확정하지 않는다.

공식 스키마의 필드 구조와 앱의 투영 정책을 비교하는 픽스처다. 서버가 이 요청을 수락한다는 증거가 아니며 실제 경로에는 연결하지 않았다. `docs/NOVELAI_API.md`의 근거·보류 조건을 함께 읽는다.

모델·sampler·noise schedule은 모두 명시적인 자리표시값이다. 이 파일의 값들을 실제 UI/서버 기본값으로 복사하지 않는다.
