# 프롬프트 라이브러리와 V3 전환 — 후속 작업

2026-11-25 (Asia/Seoul), D-059. 사용자가 승인한 다음 방향을 정리한다. 이 파일은 라이브러리가 구현됐다는 뜻이 아니다. 현재 첫 후속은 빈 카드/PNG 가져오기 사용성 정리다.

## 사용 동선

이미지 작업실과 프롬프트 라이브러리를 구분한다. 라이브러리는 프로젝트를 바꿔도 재사용하며, 작업실의 기본 프롬프트/각 캐릭터 옆에서 바로 불러올 수 있게 한다. 이름·검색·메인/캐릭터 분류부터 시작한다. 연결 설정이나 전송 기능을 라이브러리에 섞지 않는다.

| 종류 | 저장 후보 | 적용에서 제외할 것 |
| --- | --- | --- |
| 메인 프리셋 | 기본/부정 텍스트와 해당 품질·UC 자동 추가 선택 | 모델·해상도·시드·캐릭터 목록·참조 이미지 |
| 캐릭터 프리셋 | 캐릭터 긍정/부정 텍스트 | 위치·시드·해상도·활성 상태·다른 캐릭터 입력 |

메인 프리셋의 품질/UC는 텍스트 중복을 막기 위한 동반 설정이다. PNG의 최종 caption에서 만든 프리셋은 D-058처럼 자동 추가 없음으로 보관한다. 적용할 필드를 보여주고 교체/덧붙이기를 구분하며, 초기 동작은 명시적 선택으로 결정한다. 덧붙이기에서 서로 다른 프리셋의 자동 태그 선택이 충돌할 때는 숨겨서 바꾸지 않는다. 정확한 저장 스키마·원자 쓰기/삭제 복구와 IPC 범위는 구현 PR에서 별도 검토한다.

## V3 화면 전환

- 기존 V3 세션/프리셋 파일을 그대로 보존한다. 전환 완료 전 기존 메뉴를 단순히 없애 기능이 사라지게 하지 않는다.
- 기존 프리셋에서 텍스트·이름을 사용자가 선택해 가져오는 좁은 경로를 마련한다. 옛 모델 설정을 V5로 자동 해석하거나 원본을 덮어쓰지 않는다.
- V3에만 남은 인페인팅·선별·조각 편집의 이용 경로를 조사한다. 새 작업실 이관 또는 별도 도구 진입 여부를 정한 뒤 일반 메뉴의 V3 진입을 정리한다.
- 새 라이브러리 적용은 현재 입력만 바꾼다. 저장/생성·캐릭터 복제·예약 재전송을 자동 실행하지 않는다. 이미 준비한 계획은 기존 방식으로 무효화한다.

## 완료 기준

1. 메인/캐릭터 프리셋 저장·수정·불러오기, 프로젝트 전환 후 재사용.
2. 선택한 텍스트/동반 프리셋만 적용, 교체/덧붙이기·되돌리기와 미저장 입력 안내.
3. PNG 최종 caption 프리셋 재사용 시 품질/UC 중복 없음.
4. 기존 V3 가져오기 전후 원본 바이트 보존, 손상/미지원 입력은 고정 안내로 보존.
5. 기존 V3 기능의 후속 경로를 명시하고 화면 메뉴를 전환.

다음 이미지 참조는 [D-057](V5_REFERENCE_RESEARCH.md)의 V5 Full 참조1장부터 별도 진행한다. 메타데이터 불러오기를 했다는 이유로 이미지를 참조 전송 대상으로 바꾸지 않는다.
