# 작업 계획

Gemini·Claude 초기 검토를 반영한 작업 계획이다. [처리 결과](reviews/2026-11-20-review-resolution.md)에 채택·보류 이유를 기록했다. 일정과 최종 지원 범위의 확약은 아니다.

첫 재현에는 Android/iOS 패키징과 Python/BiRefNet 빌드를 요구하지 않는다. 데스크톱 설치가 실제 참조하는 서브모듈은 유지한다. 기존 App 테스트 복구는 가짜 백엔드를 마련한 뒤 진행한다. Electron 업그레이드는 재현 기준 확보 후 별도 작업으로 평가한다.

P0-03의 문서 조사와 비과금 검증은 실제 계정으로 생성에 성공한 것과 구분한다. 리뷰에 등장한 최신 모델·토큰 규격은 아직 검증한 사실이 아니다.

## P3 — 배포 정리

- 포크용 앱 식별자·업데이트 안내·배포 위치를 정리한다. 루트 `package.json`의 원본 `build.publish.owner`도 포함한다. 개발 데이터 격리는 P3까지 미루지 않는다.
- 실제 검증한 OS만 지원한다고 표시한다. 원본 CI를 그대로 성공 가능한 배포 경로로 가정하지 않는다.
- 패키징·서명·릴리스·Pages는 개발 빌드와 구분한다. 공개 배포 전에 포함 자산과 고지 자료를 확인한다.

## 작업 가져가는 방법

`STATUS.md`에서 다음 작업을 고르고 기준 SHA, 작업 ID, 수정 범위를 PR 설명에 남긴다. 검토만 할 때는 [검토 양식](reviews/TEMPLATE.md)을 사용한다. 완료 표시에는 실제 실행한 검증 근거를 연결한다.
