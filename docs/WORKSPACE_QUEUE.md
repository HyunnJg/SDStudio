# 새 작업실의 선택 씬·반복 대기열 (D-043)

현재 큐는 **V4.5 Full·512×512·28스텝·가이던스5·Euler ancestral/Karras·캐릭터 없음** 요청만 반복한다. 기존 V3·오프라인 예제 큐·다른 해상도/V5/캐릭터/와일드카드는 이 큐로 자동 전환되지 않는다. 바인딩과 v1/v2 호환은 [기본 생성](WORKSPACE_GENERATION.md), 저장/검사 범위는 [프로젝트 저장](PROJECT_STORAGE.md)에 있다.

1. API 토큰·연결 모드에서 온라인을 저장/재시작하고 앱 창에 Persistent API Token을 직접 입력한다. 기본 오프라인 정책은 유지한다.
2. 새 작업실 하단 **대기열 펼치기**에서 씬을 체크하고 반복 횟수를 입력한다. 입력은 먼저 명시적으로 저장된다. 현재 지원하지 않는 설정이면 임의 변환/전송하지 않고 오류를 알린다.
3. **입력 저장 후 선택 씬 예약 확인**에서 총 요청 수·설정·씬/반복·확정 시드를 확인한다. 준비/예약만으로 API를 보내지 않는다. 예약은 최대60건, 기존 이미지와 합쳐120기록 이내이며 요청 body 메모리도 제한한다.
4. 같은 설정·총 요청 수의 비용/사용 조건을 NovelAI 웹에서 확인하고 확인 체크 후 실행한다. 무료 여부·Anlas·Opus 사용량·서버 과금 상한을 앱이 계산/보장하지 않는다. 공간·이력 한도는 각 전송 전에 다시 검사하므로 실행 중 보관 한도에 닿으면 중지될 수 있다.
5. 저장된 씬 순서대로 반복1회를 돌고 다음 반복으로 넘어간다(A·B·C→A·B·C). 요청은1개씩이고 실제 결과는 원본 PNG·sceneId·시드·body hash/binding과 함께 프로젝트에 쌓인다. 결과 열기는 저장된 UUID 한 장만 검사/표시한다.
6. 중지는 현재 요청을 취소하고 이후 요청을 막는다. 전송된 요청의 서버 처리/사용량은 불확실할 수 있다. **미전송 작업만 새로 확인**은 pending만 대상으로 새 확인을 받고, 실패/취소된 요청을 다시 보내지 않는다. 예약/입력을 바꾸려면 취소 후 새 예약을 확인한다.

## 저장 실패·입력 변경

PNG가 유효하면 취소가 들어왔더라도 결과를 버리지 않고 저장하거나 메모리에1건 보관한다. 저장에 실패하면 큐를 멈춘다. **결과만 다시 저장**은 API를 재호출하지 않으며 이미 기록된 동일 결과 UUID/PNG를 확인해 중복 추가하지 않는다. worker 중지는 기존 수동 저장 기능 재시작을 사용한다. **입력·이번 결과만 새 프로젝트로 저장**은 기존 프로젝트/잠금/이전 PNG를 그대로 두고 이번 결과만 별도 보관한다. 이 저장이 성공하면 이전 미전송 예약을 종료한다. 새 image UUID를 이전 프로젝트의 큐 링크로 남기지 않는다.

큐 결과 append는 그 시점의 최신 manifest에 결과만 추가한다. 생성 중 다른 저장 경로에서 입력을 바꿨어도 그 입력을 덮어쓰지 않는다. 다음 요청 전에는 예약 입력 fingerprint와 다르다는 것을 확인해 중지한다. 최신 manifest를 읽은 뒤 쓰기 전에 다시 변경됐으면 기존 리비전 충돌 검사가 pending 결과를 보존한다. 실패를 자동 재전송/자동 재저장으로 숨기지 않는다.

메모리 PNG는 프로세스 종료를 견디는 journal이 아니다. 실행/미저장 PNG가 있으면 main의 정상 닫기/연결 모드 재시작을 거부한다. 중지된 **미전송 예약**은 과금 요청도 저장 데이터도 아니며 창 종료/프로세스 재시작 때 사라진다. 입력과 이미 저장된 PNG는 남는다. **미전송 예약 비우기**는 큐 기록/확인만 비우고 파일이나 PNG를 삭제하지 않는다. 미저장 PNG 버리기는 기존 별도 확인을 거친다.

## 확인한 범위

이번 검증은 합성 토큰·loopback PNG만 사용했다. 새 작업실 UI를 통한 실제 계정1장/반복 생성·실제 정확한 MIME·정상 OS 키링·Windows/macOS는 미확인이다. 사용자가 실제 검증을 할 때는 같은 UI의1장 확인부터 진행하고 성공 여부·고정 오류 코드·정제 MIME만 공유한다. 키·사용자 PNG·response.zip·개인 경로/잔액은 저장소/채팅에 올리지 않는다. [검증](validation/2026-11-23-connected-queue.md).
