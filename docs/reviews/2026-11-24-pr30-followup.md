# PR30 검토 의견 처리

기준 `dcf0433`, 병합 main `c6ceb01`. Gemini/Claude 검토는 사용자가 전달했으며 이번 구현자의 독립 검토가 아니다.

| 의견 | 처리 |
| --- | --- |
| E45가 만든 v1만 검사했다 | 사실. 기존 검증 문서를 소급 변경하지 않고 범위를 명시했다. 이번 Windows CI는 공식 해시 고정 E26.6.10 producer→E45.4.1 async/운영 store 읽기를 별도 프로필로 추가한다. 사용자 앱을 구버전으로 실행시키지 않는다 |
| 사용하지 않는 NaiTokenStore import | 사실. dcf0433과 병합본 c6ceb01의 probe 59행에 미사용 import가 있다. 이전 처리 기록의 "없다"는 구현자의 확인 오류였으며 PR31 검토 후 정정했다. PR31에서 read 단계가 실제 운영 store를 import해 legacy 파일 읽기와 별도 async 파일 왕복에 사용하도록 변경했다 |
| 운영 writer로 legacy fixture를 생성 | 고정 v1 동기 producer를 독립 유지한다. async 운영 writer로 바꾸면 과거 형식 검증이 사라진다. 실제 운영 reader와 writer/재열기/삭제도 별도로 검사한다 |
| 대기 중 삭제/교체/lock | 세대 무효화. clear/lock은 OS 작업을 기다리지 않고 이전 완료를 CANCELLED로 폐기한다. 최신 저장 대기/복호화 중 교체/외부 상위버전 교체/전송0 회귀를 추가했다 |
| 사용자 실제 Windows/V5 | 일반 npm 명령과 V5 생성 성공을 사용자 보고로 기록했다. 정확한 checkout/MIME/키링/비용은 미제공. 추가 호출·키 요청 없음 |
| 밝은 테마 생성 버튼 | 별도 UI 결함으로 분리. API/인증 변경에 화면 재설계를 섞지 않는다 |

[구현 계약](../ASYNC_TOKEN_STORAGE.md), [실행 검증](../validation/2026-11-24-async-token-store.md). Electron46 자동 업그레이드는 하지 않는다.
