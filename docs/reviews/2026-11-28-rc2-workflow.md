# 공개 rc.2에서 한 세트의 컷을 촬영하고 다시 쓰기까지

- 2026-11-28, Codex. 대상은 HyunnJg/SDStudio의 공개 태그 `v3.1.12-rc.2` (`36a40cb`), 병합본 `98baa05`다.
- Windows 공개 설치본에서 추출한 앱, 격리된 오프라인 프로필, 합성 컷 세 장으로 선별 동작을 점검했다. 예약 준비와 생성 기록 재사용은 코드 경로를 확인했다. 실제 계정 호출과 사용자 이미지 사용은 0회다.

## 작업 흐름에 대한 판단

‘같은 인물의 얼굴과 복장을 유지하며 감정별로 두 컷씩 찍고, 좋은 컷이 없는 감정만 다시 찍는다’를 기준으로 보았다. 저장한 조합, 예약 전 장수·참조 비용 확인, 결과 선별, 빈 씬 재예약, 원본 PNG·ZIP 저장까지 이어진다. 다음 개선에서 가장 먼저 줄일 동작은 후보의 얼굴을 크게 확인한 뒤 같은 후보를 썸네일에서 다시 찾아 체크하는 일이다.

소개 화면에서도 왼쪽 입력·가운데 원본·오른쪽 예약과 결과의 역할은 분명하다. 이 배치를 유지하면서 원본을 판단하는 데 필요한 조작만 가운데에 두는 편이 자연스럽다. 모델 공급자·키·처리 등급은 이미 API 설정에서 관리할 수 있다. 한 세트의 촬영에서 그 설정을 다시 여는 이유는 이번 점검에서 발견하지 못했다. ## 다음 버전에서 먼저 검증할 세 가지

| 순서 | 관찰한 동작 | 제안과 완료 기준 |
| --- | --- | --- |
| 1. 큰 화면에서 선별 | 큰 화면에 시드 73을 연 상태에서 다른 썸네일을 선별했다. 체크는 저장됐고 캔버스는 시드 73을 계속 표시했다. 씬을 고르고 ‘선별만 보기’로 한 장을 남긴 뒤 선별을 껐다 켜니 필터가 ‘전체’로 돌아가 세 장이 보였다. 현재 캔버스에는 전후 이동·선별 버튼이 없다. 큐의 새 결과를 수신하면 선택을 최신 결과로 옮기는 코드도 있다. | 현재 씬에서 이전·다음 컷을 크게 보며 그 컷을 바로 선별한다. 사용자가 과거 컷을 골라 보는 동안 새 결과가 도착해도 그 컷을 유지한다. 같은 씬의 세 컷에서 두 장을 선별하고 돌아왔을 때 같은 씬·선택·필터가 유지되고 ZIP에 고른 두 원본만 들어가는지 확인한다. |
| 2. 예약 검토에서 생길 씬 수 알기 | ‘N장 예약 검토’를 누르면 같은 이름과 입력의 씬을 재사용하고 나머지를 추가한다. 프로젝트 저장 후 예약 확인 창이 열리므로 전송을 취소해도 이미 저장한 씬은 남는다. 장수와 참조 비용만으로는 프로젝트의 60씬 중 몇 자리를 쓰는지 알기 어렵다. | 검토 버튼 옆에 `새 씬 4개 저장 · 기존 2개 사용`을 표시한다. 6개 조합을 새로 검토할 때와 같은 입력을 다시 검토할 때의 수치, 취소 후 씬 수, 한도 경계에서의 안내가 실제 저장 결과와 맞아야 한다. 기존 유료 전송 확인은 유지한다. |
| 3. 선별한 컷의 입력을 새 씬으로 복원 | 앱 생성 기록에는 실제 전개된 입력, 모델, 사용 시드와 이미지 자산 연결이 남는다. 현재 ‘설정 가져오기’는 PNG를 읽어 원하는 필드를 현재 씬에 적용하며 모델은 유지한다. | 원본 결과에 ‘이 컷의 입력으로 새 씬’을 제공한다. 다른 모델의 씬을 편집하던 중에도 원래 씬을 보존하고 선택한 컷의 모델·시드·참조 순서와 I2I 자산을 복원해야 한다. 생성 기록이 없는 가져온 PNG에서는 기존 필드 선택을 사용한다. |

## 실사용에서 한 번 더 볼 부분

저장 조합에는 컷 구성이 들어간다. 반복 횟수는 작업실 상태이고 요청 간격은 전역 설정이다. 늘 두 장씩 찍는 사용자에게는 편하지만, 용도별로 서로 다른 장수를 쓰면 다음 날에도 확인이 필요하다. 첫 사용 관찰에서는 같은 조합을 다시 열 때 반복 횟수를 실제로 고치는지 본다. 같은 동작이 반복되면 조합에 선택적으로 ‘촬영 장수 기억’을 추가할 근거가 된다. 기존 조합은 지금처럼 열 수 있어야 한다. [조합 저장과 불러오기](../../src/renderer/componenets/SceneRecipePanel.tsx)

이번 결과에서 확인한 것은 조작과 상태 변화다. 사용자의 작업 시간, 얼굴·복장 재현 품질, 개선안의 효과는 측정하지 않았다. 다음 사용성 검사는 같은 인물의 표정 세 가지를 두 컷씩 선별하고 한 조합만 다시 예약하는 짧은 작업이면 충분하다.
