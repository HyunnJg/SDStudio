| 의견 | 처리 |
| --- | --- |
| 세션 전환이 손상/미지원 버전 파일 삭제 | 채택. 세션 전환도 envelope 확인 후 삭제하며 오류 시 기존 파일/메모리 유지. 기존 손상/미지원 fixture를 두 remember 값 모두에 적용 |
| content-type 앞뒤 공백 | 채택. 비교 전 trim. 허용 MIME 확대는 실제 근거 전까지 보류 |
| 식별자 변경 시점 | 인증 UI 착수 전 포크 전용 식별·기본 프로필로 전환. 기존 원본/임시 토큰 자동 이관 없이 명시적 재입력. 다음 PR D-026에 구현 범위 기록 |
| 저장됨/로그인됨·붙여넣기 공백 | 다음 인증 UI에 채택. 명시적 앞뒤 공백 정리와 변경 안내, 상태 문구는 보관과 인증을 구분 |
| 400 진단 원문·429/실제 MIME | 운영 경로의 원문 폐기는 유지. 별도 실호출 범위에 길이 제한·로컬 전용 진단, 실제 MIME/상태/안전한 헤더 확인을 남김. 원문 로그 기능 자동 활성화 안 함 |
| 반복 복호화 | 현재 방식 유지. 실제 키링/큐 체감 지연을 확인한 뒤 결정 |
| Windows file URL 대소문자 | Windows 첫 패키지 실측 항목 유지. 확인 없이 신뢰 경계를 완화하지 않음 |
