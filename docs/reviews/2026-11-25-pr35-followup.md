# PR35 검토 의견 처리

- 검토 head `9815367`. Windows/Linux CI2/2 성공을 다시 확인하고 사용자 진행 요청에 따라 main `b3fb84b`로 병합했다.
- 캐시 충돌 지적은 **현재 PR35 호출 경로의 재현 가능한 버그로 확인되지 않았다.** ConnectedWorkspace의 `key={view.id ?? 'draft'}`가 프로젝트 전환 때 갤러리/loader 캐시를 함께 버린다. 두 번째 검토의 관찰이 현재 경로와 일치한다.
- 다음 PR에서 부모 key에 의존하지 않게 컴포넌트의 client/projectId별 queue/loader 범위를 memo로 분리하고 thumbnail key를 projectId:imageId로 명시한다. 외부 key를 제거한 실제 화면에서 같은 image UUID를 가진 복사본 전환을 검사해 현재 프로젝트 조회만 나가는지 확인한다. 기존 버그 재현과 방어적 재사용 보강을 구분한다.
- 화면 밖 재읽기/LRU는 측정 없이 바꾸지 않는다. 현재 자원 해제/직렬 읽기를 유지한다. 1100px 경계도 사용자 실제 창 피드백 전에는 유지한다.
- `.eslintignore`에 외부 `dist` 산출물을 추가해 TypeError 중단 원인을 제외한다. 이것만으로 전체 lint가 성공한 것은 아니다. 해당 범위를 제외한 기존 기준 검사에서도3044오류·31경고가 있었다. 전체 소스 포맷/레거시 규칙 정리는 별도다. 규칙 전체를 끄거나 서브모듈 소스를 고치지 않는다.
- 다음 기능은 PNG 드래그/파일 선택→항목별 메타데이터 가져오기다. 요청 간격·프로젝트 휴지통은 별도로 남긴다. 현재 회차의 생성 실계정 요청은0회다.
