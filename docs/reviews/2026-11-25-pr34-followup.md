# PR34 검토 의견 처리

- 검토 head: `0beec22`; 기준 main: `f7aa35e`. Windows/Linux 성공을 다시 확인한 뒤 사용자 진행 지시에 따라 `525c0fc`로 병합했다.
- V4.5 활성 캐릭터 안내: 지원하지 않는 **앱 경로**임을 명시하고 캐릭터 패널 바로 옆에 ‘캐릭터 조건 끄기’를 둔다. 비활성화는 텍스트/순서/cell을 보존한다.
- 생성값: 제공된 공식 화면과 앱의 값이 다르지만 UI 작업에서 값을 바꾸지 않는다. 무캐릭터/캐릭터 바인딩, v4 저장과 옛 버전 읽기/복구를 유지한다. 이번 UI 작업에 버전 승격은 없다.
- UI 의견: [D-055 배치](../WORKSPACE_LAYOUT.md)로 구현한다. 결과 오른쪽·기본/캐릭터 분리·접힌 설정·고정 생성·보조 V3 진입을 우선한다. 삭제/지연/메타데이터는 후속 범위로 기록한다.
- 중립 centers·자동 배치의 실서버 수용과 품질은 계속 미검증이다. 새 API 키/실계정 요청을 요구하지 않는다.
