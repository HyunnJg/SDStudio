# PR #13 전달 의견 처리

기준 `aee8234`. Gemini·Claude 의견을 코드와 대조한 뒤 PR #13을 `a226b63`로 병합했다. 후속은 D-031의 내부 사유·로컬 재검사다.

| 의견 | 처리 |
| --- | --- |
| 모든 형식 거부가 INVALID_IMAGE_RESPONSE로만 끝남 | main 전용 고정 사유 코드를 추가. 예: zip-eocd/zip-entry-count/zip-name/png-crc/png-trailing. 사용자 code/message·기존 auth IPC는 유지. 사유는 비열거 읽기 전용이며 runtime 허용 목록 밖 입력을 받지 않음. sendImage 재전파에서도 보존 |
| 같은 실패 응답으로 원인을 좁히기 | 읽기 전용 nai:inspect-response 추가. 로컬 파일 1개·사전/실제 읽기 한도·내용 없는 JSON. 네트워크/토큰 모듈을 금지한 테스트에서 정상 동작·원본 파일 불변을 확인 |
| 실측 실패 응답 로컬 보관 선택지 | NAI_LIVE_VALIDATION에 기본 꺼짐·지정 테스트 프로필·64 MiB/0600·공유/Git 제외 및 삭제 조건을 추가. 자동 저장은 아직 구현하지 않음 |
| STORE 결과가 ZIP 전체 버퍼의 view | STORE 결과만 독립 Uint8Array로 복사. .buffer가 정확히 PNG 영역만 담는지와 ZIP 바이트 보존을 검사 |
| 실제 응답의 flags/method/extra | 첫 실측 체크리스트에 추가. 실제 서버 형식 호환을 확인했다고 표시하지 않음 |
| 동기 CRC 비용 | 현재 구현 유지. 대기열 연결 시 이벤트 루프 지연을 측정하고 Electron/Node 업그레이드 때 native CRC 후보를 검토. 리뷰의 성능 수치는 이번에 재측정하지 않음 |
| 계정·비용·첫 모델 | 사용자 실험 재량 위임을 받음. 식별값은 기록하지 않음. 최초 계획 V4.5 Full·1회·최대 10 Anlas. 토큰 보안 입력·모델 요청 바인딩·비용 확인은 선행 조건이며 실제 호출은 0 |
