## 보완한 사실 구분

- 로컬 AI 다운로드 URL이 있는 것과 import 시 다운로드되는 것은 다르다. `download()`가 바이너리·가중치를 받고, import 경로의 `statsModels()`는 파일 확인 후 조건부 프로세스 시작으로 연결된다.
- 업데이트 루프의 시작 지점 2곳은 정적 확인이다. 네트워크 성공 여부와 실제 요청·이벤트 횟수는 아직 측정하지 않았다.
- 데이터 폴더 충돌은 구조상 가능성이며 실제 설치본과 개발 환경의 최종 경로는 아직 측정하지 않았다.
- 최신 API·모델·토큰과 폰트/데이터의 조건은 조사 과제다. 검토자의 추정을 확정 사실로 바꾸지 않았다.
