# 초기 독립 검토 요청

상태: 검토 대기. 이 파일은 요청서이며 검토 완료 보고서가 아니다.

## 배경

SDStudio를 포킹하여 NovelAI와 익숙한 이미지 생성 UI를 만들고, 재사용 조건을 확인한 오픈소스의 장점을 선별 도입하려 한다. 현재 변경은 협업 문서와 로컬 비밀 파일의 ignore 규칙뿐이다. 앱 코드와 원본 빌드 설정은 변경하지 않았다.

기준 원본: `f2088add103ad683a31e0590448e6e5bb4d71556`.
검토 시에는 이 문서가 포함된 **실제 포크 커밋 SHA**도 기록한다.

## 검토 질문

1. 원본 빌드 재현 → 외부 요청·가짜 백엔드 정리 → 화면 개편 순서가 적절한가? 불필요하게 큰 작업이 끼어 있지는 않은가?
2. 기존 씬·프리셋·대기열을 유지하면서 UI를 바꿀 최소 변경 경계는 어디인가?
3. V3 모델 매핑과 현재 목표 사이에서 먼저 확인해야 할 API·데이터 차이는 무엇인가? 근거가 없으면 미확인으로 남겨달라.
4. IP 확인 호출, 업데이트 루프, 브라우저의 Android 백엔드 선택에 관한 정적 조사 내용이 정확한가?
5. 라이선스 조사에서 빠진 고지나 파일별 구분이 있는가? 아직 확인하지 않은 라이선스를 허용된 것으로 가정하지 말아달라.
6. 와일드카드·폴더 순회 같은 후보보다 먼저 해결해야 할 실제 사용성 문제가 있는가?

결과는 [TEMPLATE.md](TEMPLATE.md) 형식으로 작성한다. 실제 API 호출이나 개인 파일 업로드는 필요하지 않다. 검토 범위를 넘는 구현은 별도 작업으로 제안한다.
