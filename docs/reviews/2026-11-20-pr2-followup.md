# PR #2 추가 검토 처리

- 출처: 사용자가 전달한 Gemini·Claude의 `793ced8` 검토. 날짜: 2026-11-20.
- 단순 칭찬·평가와 재현한 동작을 구분하고, 아래 항목을 수정했다.

| 의견 | 처리 및 검증 |
| --- | --- |
| getPath(userData)가 기본 폴더를 만들 수 있음 | 격리 모드에서는 appData/getName으로 기본 경로를 계산한다. 빈 합성 appData로 실제 Electron 드라이런 후 자식 폴더 0개 확인 |
| 디렉터리 생략 시 플래그를 폴더로 오인 | 첫 인자가 '-'로 시작하면 Electron 인자로 유지. 명시 경로와 플래그 생략 케이스 단위 검증 |
| 없는 드라이브에서 재귀 종료 불가 | 부모와 현재 경로가 같으면 명확한 오류로 중단. ENOENT를 모킹해 루트 종료 검증. Windows 실기동은 미검증 |
| start 모드 npm_execpath 누락 | Electron을 실행하기 전에 설명 있는 오류로 종료. 프로세스 테스트 통과 |
| 실제 테스트가 macOS 사용자 폴더를 볼 수 있음 | 합성 XDG_CONFIG_HOME을 쓰는 실제 Electron 테스트를 Linux 전용으로 제한. 타 플랫폼은 건너뜀 |
| root 컨테이너 추가 인자 필요 | SDSTUDIO_TEST_ELECTRON_ARGS의 JSON 문자열 배열을 명시적으로 받음. sandbox 해제 플래그를 기본값으로 넣지 않음 |
| 무시한 saveLocation 표시 | 경로 값 자체를 노출하지 않는 개발 로그를 추가. 커스텀 원본 저장 폴더는 자동 탐지하지 않음을 문서화 |
| engines와 실제 개발 하한 불일치 | Node >=22.4.1로 명확히 하고 root lock 메타데이터도 일치시킴. 의존성 버전 변경 없음 |
| 동봉 바이너리·플랫폼 한계 | 설치 코드에서 sharp libvips 다운로드 경로 확인. Windows npm ci 미검증과 별도 다운로드를 기록 |
| 커밋 범위 | 프로필 보완과 엔진/lock 메타데이터를 별도 후속 커밋으로 나눔. 기존 커밋은 재작성하지 않음 |

검증: 프로필 단위/진입·명령 인자 테스트 11건, Linux 실제 Electron 테스트 2건 통과. 새 TS 모듈의 엄격 타입검사·린트 통과. 전체 UI와 외부 요청 제어는 후속 P0-02에서 검증한다.
