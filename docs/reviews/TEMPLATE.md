# 검토 제목

- 작성일:
- 검토자 / 모델·버전(알고 있는 경우):
- 작업 ID / 검토 범위:
- 저장소 / 브랜치 / 실제 커밋 SHA:
- 읽은 파일:
- 실행한 검증 / 미실행 항목:

## 판단

진행 가능 / 수정 후 진행 / 추가 확인 필요 중 하나와 핵심 이유를 적는다.

## 잘 유지해야 할 부분

구체적인 근거를 적는다.

## 불확실한 부분

읽지 못한 자료, 실행하지 않은 동작, 추가 증거가 필요한 주장을 구분한다.

## 다음 작업 제안

작게 검증할 수 있는 작업과 완료 기준을 적는다.

## 처리 결과 — 구현 담당자가 작성

각 의견의 채택/보류/기각, 이유와 관련 커밋 또는 PR 링크를 적는다. 리뷰어의 원래 의견을 덮어쓰지 않는다.
