# Windows 작업실 백업과 복원

작업하던 프로젝트와 ‘조합으로 예약’에서 저장한 조합을 함께 옮기려면 아래 세 폴더를 같은 시점에 복사한다. 조합은 화풍과 인물 프리셋을 ID로 기억하므로 라이브러리도 함께 복원해야 같은 입력을 불러올 수 있다.

| 프로필 아래 경로 | 보관되는 내용 |
| --- | --- |
| `projects-v1` | 씬, 결과 PNG, 이미지 입력, 이력, 선별 상태 |
| `prompt-library` | 저장한 메인·캐릭터 프리셋과 ID |
| `chromium\Local Storage` | 저장한 조합과 작업 화면의 로컬 설정 |

1. 진행 중인 생성과 저장을 마친 뒤 앱을 완전히 종료한다. 파일 탐색기 주소 표시줄에 `%APPDATA%\SDStudio-HyunnJg`를 입력한다. 격리 실행을 사용했다면 지정한 프로필 폴더를 연다.
2. 날짜를 붙인 개인 백업 폴더를 만들고 표의 폴더를 하위 경로까지 그대로 복사한다. `Local Storage`에는 개인 설정도 들어갈 수 있으므로 개인 보관용으로 다룬다. API 자격증명은 이 절차의 복사 대상에서 제외한다.
3. 복원할 때는 앱을 종료하고 대상의 기존 세 폴더를 먼저 별도 보관한다. 대상에 각 폴더가 없는 상태에서 백업본을 원래 상대 경로에 넣는다. 파일 단위로 섞으면 프로젝트 이력과 라이브러리 또는 브라우저 저장소의 버전이 서로 달라질 수 있다.
4. 같은 설치 경로에서 앱을 열어 프로젝트의 최근 PNG와 선별 상태를 확인한다. ‘조합으로 예약 → 저장한 조합’에서 하나를 선택하고 연결해 둔 공통 화풍과 인물 이름을 확인한다. 새 프로필의 API 연결은 필요할 때 다시 설정한다.

검증 범위는 같은 Windows 계정과 같은 앱 실행 경로의 두 프로필이다. 오프라인 등대 프로젝트에서 결과 3장, 그중 선별 1건, 저장한 조합과 원래 화풍 프리셋 ID가 새 프로필에서 복원됐다. 다른 PC나 설치 경로로 이동할 때는 새 환경에서 조합까지 확인한 뒤 원래 백업을 정리한다. 실행 중이던 생성 큐는 이 방법으로 이어서 실행할 수 없다.
