## 이번에 확인한 사실

- 기존 장점: 씬별 예약 생성, 이미지 선별, 인페인팅, 프롬프트 조각과 조합. 원본 README와 해당 소스가 존재한다. 현재 환경에서 기능 작동을 검증한 것은 아니다.
- `src/renderer/backends/genVendors/nai.ts`는 `nai-diffusion-3` 계열을 매핑한다. 최신 모델 호환성은 별도로 확인해야 한다.
- 원본 전체 트리에서 독립된 LICENSE/NOTICE 파일은 찾지 못했다. 루트와 배포 패키지는 MIT, 네이티브 패키지는 ISC로 표기한다. [확인 범위](LICENSE_REVIEW.md)를 참고한다.
- 생성 경로에는 원본 운영자의 IP 확인 서비스 호출이 있고, 업데이트 안내도 원본 릴리스를 참조한다. 포크 사용 전에 필요성과 동작을 점검한다. [위치와 범위](ARCHITECTURE.md)를 참고한다.
- 업데이트 서비스는 생성자와 조립 모듈 양쪽에서 `run()`을 시작한다. 중복 시작 경로는 정적 소스로 확인했고 실제 요청 횟수는 미실측이다.
- 데이터 기본 경로와 앱 이름이 원본과 같다. 실제 프로필 충돌은 미실측이지만 첫 앱 실행 전에 경로를 격리한다. 원본 `config.saveLocation`을 읽어 다시 원본 폴더를 선택하는 경로도 확인한다.
- `<모음.조각>`과 `multi` 랜덤 선택은 이미 구현돼 있다. 선택은 `Math.random()`을 사용한다. P2-01을 새 기능이 아닌 재현성·기록 개선으로 수정했다.
- 원본 CI에는 다중 OS 패키징, 서명, 릴리스 및 Pages 배포 구성이 있다. 이 포크에서 활성화하거나 실행하지 않았다.

## 바로 다음 작업

1. **P0-01a / P0-02:** 빈 개발 프로필과 외부 요청 통제를 먼저 마련한다. 구현은 작업별 브랜치·PR로 분리한다.
2. **P0-01:** Electron 데스크톱만 우선 설치·빌드·기동 재현한다. 앱 기동은 위 조건 뒤에 수행하고 성공한 의존성을 lock 파일로 고정한다.
3. **P0-03 / P0-04:** 모델/API 지원 범위와 저장 호환 설계, 누락 자산 고지 조사를 진행한다. 이 문서 정리에서 최신 API 규격이나 자산 라이선스를 확정하지 않았다.
4. **P1-01:** P0-03 결정을 반영해 기존 서비스 위에 화면을 조립한다. 모델·저장 형식 변경은 별도 PR로 다룬다.

상세 완료 기준은 [ROADMAP.md](ROADMAP.md)에 있다. 검토자는 저장소를 읽은 **실제 커밋 SHA**를 의견에 적는다.

## 미정 사항

- 최종 앱 이름, 색상·세부 배치.
- 최신 NovelAI 모델 중 지원할 정확한 범위와 파라미터.
- 외부 오픈소스 후보 및 실제 도입할 코드.
- 첫 배포 시점과 지원 OS 범위. 첫 실행 재현은 개발 편의를 위한 제안이며 지원 정책 확정이 아니다.
