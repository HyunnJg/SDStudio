# 메인·캐릭터 프롬프트 라이브러리 — D-060

2026-11-25 (Asia/Seoul), 기준 main `a0860c2`(PR37 병합). 새 작업실 상단의 ‘프롬프트 라이브러리’, 입력 패널의 메인 프리셋 버튼, 각 캐릭터 카드의 저장·불러오기를 사용한다. 프로젝트를 바꿔도 같은 라이브러리를 쓴다.

## 저장과 적용

| 종류 | 보관하는 값 | 적용하지 않는 값 |
| --- | --- | --- |
| 메인 | 이름·기본/부정 텍스트·품질/UC 자동 추가 선택 | 모델·크기·스텝·시드·캐릭터·참조 |
| 캐릭터 | 이름·긍정/부정 텍스트 | 기존 캐릭터 UUID·활성 상태·위치·다른 카드·모델/시드 |

- 현재 입력으로 새 초안을 만들고 이름을 붙여 저장한다. ‘라이브러리에 저장’은 작업실 입력/프로젝트/대기열을 바꾸거나 생성을 시작하지 않는다. 반대로 ‘선택한 항목 적용’은 현재 씬 입력만 바꾸며 라이브러리·프로젝트를 자동 저장하지 않는다.
- 교체/덧붙이기와 적용할 긍정·부정·품질/UC를 고른다. 덧붙이기는 원문을 자르지 않고 줄바꿈으로 이어 붙인다. 방식을 바꾸면 품질/UC 동반 적용을 끄며, 사용자가 다시 고를 수 있다. 현재/프리셋 설정 차이는 미리보기에 표시한다.
- PNG에서 최종 caption을 가져온 입력은 D-058의 자동 추가 없음 상태 그대로 프리셋에 저장된다. 재사용할 때 품질/UC도 선택하면 태그를 다시 붙이지 않는다. 자동 추가를 유지하며 최종 태그 텍스트만 덧붙이면 중복될 수 있음을 화면에 안내한다. 태그를 추정해 삭제/변환하지 않는다.
- 캐릭터는 기존 카드를 골라 그 UUID의 텍스트만 바꾸거나, ‘새 캐릭터로 추가’를 명시적으로 고른다. 비활성/위치/순서를 바꾸지 않으며 새 카드만 기본 활성/중립 위치다. 전체32개 보관 한도를 유지한다.
- 최근 입력 적용은 이후 입력이 더 바뀌지 않았을 때 한 번 되돌릴 수 있다. 프로젝트·씬이 바뀌면 수명을 분리한다. 적용 시 준비된 단일/큐 확인을 비우고, 기존 큐의 초안 비교가 다음 요청 전에 변경을 검사한다.
- 라이브러리 편집을 저장하지 않고 닫기/다른 항목으로 이동/기존 도구로 전환하려면 편집 버리기를 명시한다. 정상 앱 닫기·연결 재시작은 진행 중 라이브러리 작업/편집을 먼저 마치도록 안내한다. 강제 종료/정전 때 메모리 편집 복원을 보장하지 않는다.

## 로컬 저장 계약

- 프로필의 `prompt-library/library.v1.json`, `format: sdstudio-prompt-library`, version1이다. 프로젝트/V3 세션 형식은 바꾸지 않는다. 프롬프트 텍스트를 JSON으로 보관하며 토큰 저장소/계정 자료를 읽지 않는다.
- snapshot은 현재 파일 바이트 SHA-256 리비전과 전체 항목을 반환한다. 항목은 UUID·kind·name·prompt·negativePrompt·deleted, 메인에만 qualityTags/ucPreset이다. 모델·시드·임의 경로 등 추가 키를 거부한다.
- IPC는 read/save/setDeleted/remove뿐이다. 승인된 최상위 창을 await 전후 검사하고 고정 오류 코드만 반환한다. renderer는 파일 경로를 주거나 임의 파일을 읽을 수 없다. 오프라인에서도 사용할 수 있다.
- 한 앱의 저장 작업을 직렬화하고 기대 리비전이 다르면 거부한다. 새 임시 파일을 wx/0600으로 만들고 파일 fsync→rename한다. POSIX에서는 디렉터리 fsync도 수행한다. Windows 디렉터리 fsync/전원 손실 내구성을 보장한다고 설명하지 않는다.
- 같은 파일을 두 앱/외부 편집기가 동시에 쓰는 경우에 대한 OS 전역 잠금은 아니다. 일반 앱의 기존 단일 인스턴스 정책을 전제로 하며, 읽은 뒤 감지한 외부 변경은 충돌로 거부한다. 같은 사용자 권한의 악성 프로세스를 막는 샌드박스가 아니다.
- 읽기는 일반 파일/비링크·fd inode/device·크기·정확한 바이트 수·UTF8·스키마를 확인한다. 손상/미지원 버전은 보존하고 덮어쓰지 않는다. 폴더 링크도 거부한다. 파일2MiB·항목200(휴지통 포함)·프롬프트/부정 각각65,536 UTF-16 코드 단위·이름120자 상한이다. I/O는 비동기이며 작은 JSON 파싱/해시 자체는 동기다.
- 삭제는 우선 휴지통으로 이동하며 복원할 수 있다. 휴지통에서만 별도 확인 후 영구 삭제한다. 한도에 닿으면 휴지통의 불필요한 항목을 직접 정리하거나 기존 항목을 수정한다. 오래된 항목을 자동으로 지우지 않는다.
- 쓰기 오류 뒤 교체됐을 가능성이 있으면 새로고침으로 목록을 확인한다. 자동 재쓰기/생성은 하지 않는다. 임시 파일만 정리하며 성공 여부를 모르는 원본을 임의로 지우지 않는다.

## V3 전환 범위

새 라이브러리를 일반 메뉴와 입력 옆에 노출했다. 기존 V3 메뉴는 ‘기존 도구 · 인페인팅·선별’로 구분하며, 라이브러리에서도 해당 도구로 이동할 수 있다. 기존 V3 코드와 이미지 생성/인페인팅/선별/조각 편집을 삭제한 것은 아니다. 미이관 도구를 포팅하기 전 기능을 없애지 않는다.

사용자가 내보낸 V3 세션 JSON(최대2MiB)을 선택하면 알려진 `SDImageGen`/`SDImageGenEasy` 프리셋의 이름·frontPrompt/backPrompt·uc만 후보로 읽는다. Easy 공유 캐릭터는 캐릭터 후보, 공유 배경/공통 부정은 메인 후보로 분리한다. 원문은 줄바꿈으로 연결하고 모델·샘플러·시드·이미지/경로·씬 중간 입력·조각 전개는 가져오지 않는다. 후보를 열고 확인한 뒤 저장해야 하며 원본 파일은 쓰지 않는다. 기존 V3 폴더를 자동 탐색/변환하지 않는다.
