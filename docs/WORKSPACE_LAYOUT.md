# 이미지 작업실 배치 — D-055

기준은 PR34 병합 `525c0fc`다. 사용자가 제공한 NAI 화면의 입력/캔버스/이력 동선을 참고하고, 기존 SDStudio 색·컴포넌트를 재배치했다. 공식 코드·이미지·로고나 스크린샷의 프롬프트/계정 수치는 제품에 넣지 않는다.

- **왼쪽:** 모델·크기, 기본/부정 프롬프트 탭, 여러 캐릭터의 개별 프롬프트. AI 설정은 접힌 요약으로 시작하고 스텝·가이던스·시드·프리셋은 펼쳐 편집한다. 접기/탭 전환은 입력을 지우거나 설정을 바꾸지 않는다.
- **고정 실행부:** 왼쪽 아래 생성·상태·중지. 단일 생성의 저장→준비→전송, 높은 스텝 확인, 큐 묶음 확인, 미저장 PNG 저장-only 복구는 기존 계약을 그대로 사용한다. 확인과 저장 복구는 중앙의 독립된 스크롤 영역으로 보인다. 어두운 테마도 강조색 민트/어두운 글자, 밝은 테마는 초록/흰 글자를 의도적으로 사용한다.
- **가운데:** 선택한 원본 PNG를 contain으로 표시한다. 편집용 재인코딩/메타데이터 변경은 없다.
- **오른쪽:** 결과 또는 씬·대기열. 결과는 최신순·원본 비율 미리보기, 선택하면 중앙에서 연다. 씬 선택·예약·미전송 이어가기/제외·결과 링크의 동작은 유지한다. 새로 저장된 결과 목록은 기존 controller 스냅샷을 사용한다.
- **작은 창:** 1100px 이하에서는 오른쪽 패널을 ‘결과·씬’으로 연다. 680px 이하에서는 입력/이미지 화면을 전환하고 실행부는 아래에 남는다. 생성 결과·추가 확인·미저장 PNG는 이미지 영역으로 이동시켜 안내한다. 실제 앱의 기존 최소 창 크기는 변경하지 않는다.
- **보조 작업:** 토큰/연결·테마·기존 V3 진입은 메뉴에, 새 입력·복사본 작업은 프로젝트 메뉴에 있다. 저장·열기/복구와 고정 오류는 직접 접근한다. V3를 제거하거나 자동 변환하지 않는다.

## 미리보기 읽기 수명

미리보기는 기존 manifest UUID 한정 `generation.image` IPC만 쓴다. IntersectionObserver가 화면 근처(80px 여유)에 들어온 항목만 요청하고, thumbnail queue가 한 갤러리의 읽기를 직렬화한다. 선택 결과는 중앙의 object URL을 재사용한다. 전체 프로젝트 open이나 전체 PNG 재검사를 추가하지 않는다.

화면 밖/탭 숨김/프로젝트 교체 시 대기 작업을 제거하고 object URL을 해제한다. 이미 시작한 worker 읽기 자체를 취소하는 IPC는 없으므로 그 완료를 기다리고 늦은 결과만 버린다. 원본 PNG(최대32MiB)를 그대로 읽기 때문에 압축된 썸네일 전용 저장소만큼 가볍지는 않다. 현재 범위는 전체120장 선로딩과 매 폴링 재요청을 막는 것이다. IntersectionObserver가 없으면 버튼만 보이고 선택한 이미지를 중앙에서 연다.

## 이번에 바꾸지 않는 항목과 다음 작업

후속은 별도로 나눈다: 프로젝트 휴지통/명시적 삭제와 복원, 요청 사이 간격(사용자 제안5~10초; 안전한 공식 간격으로 확정하지 않음), PNG 드래그→메타데이터 항목별 미리보기/가져오기(프롬프트·UC·캐릭터·설정·시드), V3 편집 기능 이동. i2i PNG의 메타데이터만으로 원본 결과를 완전히 재현할 수 있다고 안내하지 않는다. 캐릭터 수동 배치도 후속이다.
