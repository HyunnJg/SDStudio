## Opus와 잔액 기록

사용자가 Opus에서는 Anlas보다 할당량이 소모된다고 설명했다. 이 설명과 숫자로 확인한 잔액 기록을 구분한다. Anlas잔액 관찰차이0은 사용량/할당량 변화가0이라는 뜻이 아니다. 현재 도구는 할당량 조회나 감소 추적을 구현하지 않았다.

2026-11-22 확인한 [공식 구독 문서](https://docs.novelai.net/en/subscription/)는 Opus의 조건부 Anlas무료 생성과 V4.5보다 높은 모델의 usage limit을 구분한다. V4.5이하의 조건부 생성은 사실상 무제한이라고 안내한다. 따라서 이번 V4.5후보의 할당량이 실제 감소했다고 문서만으로 확정하거나, Opus의 모든 설정/모델이 무조건무료라고 일반화하지 않는다. 계정의 실제 웹 표시와 구독·설정 조건을 기준으로 한다.
