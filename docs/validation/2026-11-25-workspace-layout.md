## 패키지(ASAR)와 한계

Linux 디렉터리 패키지의 generation **15체크**와 characters **8체크**가 최종 통과했다(루프백 각3회). 두 실행 모두 app.isPackaged=true·ASAR 실행 전후 해시 동일·프로필 격리·원격/renderer 오류0을 확인했다. worker는 ASAR 안의 제품 번들을 사용하고, 검사 하네스만 inspector로 주입했다. 첫 generation 실행에서는 제품의15개 체크가 모두 성공했으나 runner가 이전11개를 기대해 종료 코드1이었다. runner의 정확한 기대 건수를 새 검사와 맞췄고 제품 코드는 완화하지 않았다.
