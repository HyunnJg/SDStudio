# Application license record

The SDStudio root and release/app package.json declare MIT; src/native/package.json declares ISC. Original author metadata is retained in those files.

The root LICENSE is an exact restoration from ancestor commit 7091c9135bf0ddd29710e78f907906db96ea4975 of sunho/SDStudio. It contains the Electron React Boilerplate MIT notice, copyright 2015-present Electron React Boilerplate. It was deleted in fb2582c02ef184eac8a7b441075660d20151ab93. We have not invented or substituted an application-specific copyright holder or year.

This restored historical notice does not resolve the absence of a separate SDStudio-specific copyright notice. The native module declares ISC but an exact notice file has not yet been identified. These remain review items before public distribution.

THIRD_PARTY_NOTICES.txt and index.json contain local dependency notice evidence, including unresolved entries. They do not clear the provenance of tag data, images or vendored binaries, and do not certify full redistribution compliance.
