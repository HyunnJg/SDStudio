# 첫 실제 생성 검증 계획 — 아직 실행하지 않음

2026-11-21. P0-03b2의 합성 응답 검증과 분리한다. 현재 실제 인증/생성 요청 수와 승인된 지출은 **0**이며 이 문서는 호출 승인이 아니다.

| 항목 | 실행 전 확정할 값 / 현재 상태 |
| --- | --- |
| 사용할 계정 | 사용자 지정 필요. 이메일/토큰을 이 문서나 PR에 기록하지 않음. 보안 설정창에 직접 입력 |
| 모델 | 첫 목표 V4.5 Full. API ID·필수값은 미확정. 후보와 근거를 확인하고 요청 본문을 검토 |
| 요청 수 | 최초 검증 계획은 1회만 제안. 실패·취소 뒤 재호출은 자동 진행하지 않고 결과/서버 처리 가능성을 먼저 검토 |
| Anlas 상한 | 사용자 지정 필요. 해상도/스텝/구독 조건으로 무료라고 추정하지 않음. 상한이 없거나 비용 확인이 안 되면 실행하지 않음 |
| 중지 조건 | 승인 수/금액 도달, 인증/한도/서버 오류, 예기치 않은 형식, 기한/취소, 비용 확인 불가. 자동 재시도 없음 |
| 온라인 선택 | 일반 포크의 연결 모드 저장·재시작 뒤 적용. 테스트에서 외부 차단을 푸는 것은 별도 실행 범위 |
| 요청 검토 | model/action/params_version, sampler/noise schedule, n_samples=1, 캐릭터 긍정·부정 대응, 좌표/자동 배치·use_order 등 미확정 항목 |
| 기록 | 정제된 HTTP 상태·실제 MIME·ZIP 형식/크기·PNG 바이트 보존·실제 사용 시드·서버 처리 가능성. 토큰/프롬프트/원시 서버 본문은 PR/로그에 넣지 않음 |
| 오류 진단 | 필요하면 사용자가 명시적으로 선택한 길이 제한 로컬 오류 진단을 별도 구현/검토. 현재 운영 경로는 오류 본문 폐기 |
| 결과 보관 | 최초에는 지정한 테스트용 포크 프로필/출력만 사용. V3/원본 데이터의 암묵적 변환 없음 |

공식 [Image API 스키마](https://image.novelai.net/docs/doc.json)는 Persistent API token을 요구하지만 모델 ID/기본값 목록을 완성하지 않는다. 값이 공식 자료로 확정되지 않으면 이를 검증 가설로 기록하며, 합성 fixture가 서버 호환을 증명한다고 표시하지 않는다. 비용 범위가 필요한 시점에는 최종 요청·계정·상한을 구체화한 뒤 사용자와 확정한다.
