# 첫 실제 생성 검증 계획 — 아직 실행하지 않음

2026-11-21. P0-03b2의 합성 응답 검증과 분리한다. 실제 인증/생성 요청과 지출은 현재 **0**이다. 사용자가 실험 진행 재량을 위임했으며 계정 식별값은 비공개로 취급한다. 최초 계획은 담당자가 보수적으로 **V4.5 Full·1회·최대 10 Anlas**로 정한다. 실제 토큰 보안 입력·모델 요청 바인딩과 비용 확인은 실행 전 선행 조건이다.

| 항목 | 실행 전 확정할 값 / 현재 상태 |
| --- | --- |
| 사용할 계정 | 사용자 지정 계정. 식별값/이메일/토큰은 문서나 PR에 기록하지 않음. Account ID는 API 인증 토큰으로 사용하지 않음. Persistent API Token을 앱의 보안 설정창에 직접 입력 |
| 모델 | 첫 목표 V4.5 Full. API ID·필수값은 미확정. 후보와 근거를 확인하고 요청 본문을 검토 |
| 요청 수 | 최초 1회. 실패·취소 뒤 재호출은 자동 진행하지 않고 결과/서버 처리 가능성을 먼저 검토 |
| Anlas 상한 | 첫 실험 최대 10 Anlas(위임 범위에서 정한 보수적 계획). 해상도/스텝/구독 조건으로 무료라고 추정하지 않음. 실제 요청 비용이 한도 이내인지 확인할 수 없으면 전송하지 않음 |
| 중지 조건 | 승인 수/금액 도달, 인증/한도/서버 오류, 예기치 않은 형식, 기한/취소, 비용 확인 불가. 자동 재시도 없음 |
| 온라인 선택 | 일반 포크의 연결 모드 저장·재시작 뒤 적용. 테스트에서 외부 차단을 푸는 것은 별도 실행 범위 |
| 요청 검토 | model/action/params_version, sampler/noise schedule, n_samples=1, 캐릭터 긍정·부정 대응, 좌표/자동 배치·use_order 등 미확정 항목 |
| 기록 | 정제된 HTTP 상태·실제 MIME·ZIP 형식/크기·PNG 바이트 보존·실제 사용 시드·서버 처리 가능성. 토큰/프롬프트/원시 서버 본문은 PR/로그에 넣지 않음 |
| 오류 진단 | 고정 내부 사유 코드만 명시적 검증 기록에 포함. 사용자 화면/기존 auth IPC는 공개 오류 코드만 유지. 현재 운영 경로는 오류 본문 폐기 |
| 결과 보관 | 최초에는 지정한 테스트용 포크 프로필/출력만 사용. V3/원본 데이터의 암묵적 변환 없음 |

공식 [Image API 스키마](https://image.novelai.net/docs/doc.json)는 Persistent API token을 요구하지만 모델 ID/기본값 목록을 완성하지 않는다. 값이 공식 자료로 확정되지 않으면 이를 검증 가설로 기록하며, 합성 fixture가 서버 호환을 증명한다고 표시하지 않는다. 실행 전 위임 범위 안에서 최종 요청·계정·상한·중지 조건을 구체화하고 검증한다. 계정 식별값과 인증값은 공개 문서에 남기지 않는다.


## 실패 응답의 로컬 재검사

실제 응답 첫 확인에서 ZIP flags/method/extra 형식과 단일 엔트리 등 현재 프로필의 대응을 기록한다. 원시 파일명/본문을 검증 기록에 붙이지 않는다. 실패가 나도 반복 과금 호출로 원인을 좁히기 전에 내부 사유 코드를 보고 같은 응답의 로컬 재검사를 우선한다.

```sh
npm run nai:inspect-response -- /absolute/test-profile/response.zip
```

도구는 지정한 파일만 읽고 API/토큰을 사용하지 않으며 파일을 수정하거나 이미지/원문을 출력하지 않는다. 결과는 공개 오류 코드·고정 사유·바이트 수뿐이다. 이 도구는 실패 응답을 자동 수집하지 않는다.

원본 보관이 필요하면 별도 명시적 선택으로 사용자가 고른 테스트 프로필의 비공개 폴더에만 저장하는 기능을 후속으로 검토한다. 기본 비활성·64 MiB 한도·0600 파일, 원본 바이트 그대로/자동 덮어쓰기 없음, Git/공유 결과 제외와 명시적 삭제를 조건으로 한다. ZIP/PNG에 프롬프트 metadata가 포함될 수 있어 공개 진단 자료에 원문을 넣지 않는다. 현 기능은 재검사이며 자동 보관 기능은 아직 없다.
