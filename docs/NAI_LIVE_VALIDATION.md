# 첫 실제 생성 검증 — 실행 도구 준비, 실제 호출 대기

2026-11-21 (Asia/Seoul). 실제 인증/생성 요청과 지출은 현재 **0**이다. 사용자의 실험 재량 위임을 유지하며 계정 식별값은 기록하지 않는다. 최초 범위는 **V4.5 Full 후보·요청 1회·웹 표시 비용 10 Anlas 이하**다. 이는 앱이 보장하는 서버 측 과금 상한이 아니다.

## 이번 경로

일반 앱의 작업실/대기열이 아니라 개발 체크아웃의 **별도 Electron 실험 창**을 사용한다. 기존 토큰·프로젝트를 검색하거나 가져오지 않는다. 실제 Persistent API Token은 사용자가 자기 PC의 이 창에 직접 입력한다. 채팅·CLI 인자·환경변수·Git에 넣지 않는다. 이번 실행의 메모리에만 보관하며 전송 시도 후 또는 창 종료 시 사본을 버린다. Account ID나 계정 비밀번호는 인증 토큰이 아니다.

[실행 안내](DEVELOPMENT.md#1회-실호출-검증-도구-d-032), [합성 검증](validation/2026-11-21-live-validation.md), 결정 D-032를 함께 읽는다. 실제 토큰이 없는 현재 환경에서는 합성 루프백 검증까지만 수행했다.

## 고정 후보와 확인 범위

`.erb/fixtures/nai-live-candidate.json`은 **unverified-experimental-candidate**다. 운영 모델 목록이나 UI 기본값으로 쓰지 않는다. 공식 [Image API 스키마](https://image.novelai.net/docs/doc.json)의 model은 string이며 모델 ID enum·모델별 기본값은 확인되지 않았다. 아래 값은 서버 수락 여부를 실험할 가설이다. 비공식 구현의 문자열을 공식 확인 사실로 승격하지 않는다.

| 필드 | 이번 실험 후보 |
| --- | --- |
| model / action / params_version | nai-diffusion-4-5-full / generate / 3 |
| 크기 / steps / scale | 512×512 / 28 / 5 |
| sampler / noise_schedule / cfg_rescale | k_euler_ancestral / karras / 0 |
| seed / n_samples | 0 / 1 |
| 프롬프트 | 자체 합성 풍경 문구. 전체 고정 JSON은 창에서 확인 |
| 캐릭터 / 배치 | char_captions 빈 배열, use_coords=false, use_order=true. 부정 조건에도 같은 키를 넣는 가설 |

캐릭터·격자·참조 입력, V5, 새 프로젝트 저장 호환은 이번 단일 기본 요청이 성공해도 검증되지 않는다. ZIP flags/method/extra 길이는 숫자만 기록한다. 현재 좁은 ZIP/PNG 프로필과의 호환도 실제 응답에서 확인해야 한다.

## 비용 확인과 실행 순서

1. 다른 창/대기열의 생성을 멈추고 테스트 프로필을 저장소 및 원본/포크 기본 프로필 밖에 고른다. 정상 앱의 온라인 설정을 바꾸는 실험이 아니다.
2. 실험 창의 고정 JSON을 펼쳐 확인한다. NovelAI 웹에서 **동일한 모델·해상도·스텝·샘플러·부가 설정**의 표시 비용과 현재 잔액을 직접 확인한다. 웹에서 실제로 생성할 필요는 없다. 동일 설정의 비용을 확인할 수 없다면 전송하지 않는다.
3. 창에 실행 전 잔액과 웹 표시 비용을 입력한다. 같은 설정 확인·비공개 원문 보관·미확인 후보라는 세 항목을 직접 선택한다. 입력값과 고정 요청 SHA-256을 묶어 기록한다. 구독 이름이나 해상도만으로 무료라고 추정하지 않는다.
4. 표시 비용 0~10, 잔액 충분, 토큰 로컬 읽기, 강제 오프라인 없음, 기록 파일 생성이 모두 통과한 뒤에만 **실제 API 1회 전송**을 누른다. 키가 맞는지 확인하는 별도 계정 API는 호출하지 않는다.
5. 응답/오류 뒤 웹 잔액을 다시 확인해 실행 후 잔액을 기록한다. 실행 전 잔액·표시 비용은 attempt.json, 실행 후 잔액·관찰 차이는 balance-after.json에 각각 남는다. 잔액 차이는 다른 활동·갱신 지연의 영향을 받을 수 있어 이 요청의 과금 증명이 아니다.
6. 실패·취소·기한 초과·서버 형식 불일치 때 자동 재시도하지 않는다. 같은 프로필의 두 번째 전송도 막힌다. 결과와 서버 처리 가능성을 먼저 검토한다. 재호출을 위해 기록을 지우거나 새 프로필을 자동 생성하지 않는다.

비용 입력은 **사용자의 웹 확인 진술**이다. 앱은 서버 가격을 독립 계산하거나 실제 청구를 제한하지 않는다. 위임된 최초 범위를 이 구분 없이 “10 Anlas 강제 과금 한도”로 설명하지 않는다.

## 비공개 응답 보관과 재검사

실험 실행 및 보관 선택 전에는 응답을 수집하지 않는다. 실험 경로만 `diagnosticCapture`를 명시적으로 켠다. 일반 앱의 전송기는 여전히 오류 본문을 폐기한다. 받은 이미지 응답은 최대 64 MiB이고 **해제/검증 전에** 선택한 프로필의 live-validation/response.zip에 원본 그대로 보관한다. 비 2xx 또는 2xx MIME 불일치의 오류 본문은 최대 64 KiB만 보관하고 잘렸으면 captureTruncated=true를 기록한다. 이때 확장자가 zip이어도 실제 내용은 JSON/텍스트일 수 있다.

| 로컬 파일 | 내용 |
| --- | --- |
| attempt.json | 요청 해시·시각·수동 확인 비용/실행 전 잔액·1회 계획 |
| response.zip | 비공개 응답 원문. 이미지/프롬프트 metadata 또는 서버 오류 내용이 있을 수 있음 |
| result.json | 허용된 오류 코드·고정 사유·HTTP 상태·분류 MIME·바이트 수·서버 처리 가능성 |
| result.png | 검증 성공 때만 원본 PNG. 재인코딩하지 않음 |
| balance-after.json | 수동 실행 후 잔액과 관찰 차이. 덮어쓰기 없음 |

Linux에서 보관 디렉터리 0700/동일 소유자·링크 거부, 파일 wx/0600을 확인했다. attempt/응답/JSON은 fsync하며 기존 파일은 덮어쓰지 않는다. Windows ACL과 macOS 실기는 미검증이다. 선택한 폴더는 사용자가 비공개로 관리한다. 원문 파일/PNG·개인 경로·계정/토큰을 PR이나 공유 로그에 올리지 않는다.

전송 전에 attempt.json을 선점하므로 실패/충돌/프로세스 재시작도 추가 요청을 자동 허용하지 않는다. 이 파일이 남았다는 사실이 전송이나 과금을 증명하지는 않는다. 응답 전 취소·네트워크 단절이면 빈 response.zip 예약 파일만 남을 수 있고 **responseCaptured=false**다. 수신 상한 초과·중간 연결 단절에도 완전한 응답 보관을 보장하지 않는다. 보관 실패는 RESPONSE_CAPTURE_FAILED이며 다시 보내지 않는다.

```sh
npm run nai:inspect-response -- /absolute/test-profile/live-validation/response.zip
```

responseCaptured=true인 파일을 로컬에서 재검사한다. HTTP 오류 본문이면 ZIP 검사에서 거부되는 것이 정상이다. 도구는 API/토큰 없이 파일 하나를 읽고 고정 코드·사유·바이트 수만 출력한다. 과거 서버 처리/과금을 판정하지 않는다. 불량 ZIP 합성 테스트에서 보관 파일과 재검사 사유 zip-eocd가 같음을 실제 Electron 창에서 확인했다.
